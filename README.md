## 👨‍💻 About Me

I'm an Application Developer with a Bachelor's degree in Information Technology, awarded the **Special Distinction Award for Programmer of the Year**.

Currently working at **Virginia Food Inc.**, developing and maintaining business applications across web, mobile, and backend systems.

My primary focus is backend development, API integration, database management, and building maintainable application architectures. I also work with frontend technologies, mobile development, and cloud infrastructure.

**What I do:**
- Build and maintain web, mobile, and desktop applications.
- Develop RESTful APIs and backend services.
- Design databases, stored procedures, and optimize SQL queries.
- Implement authentication and authorization mechanisms.
- Manage and deploy applications using AWS infrastructure.
- Develop maintainable software using modular and scalable architectures.
